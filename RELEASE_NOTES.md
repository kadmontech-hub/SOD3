# SØD Ecosystem Visual MVP V3.0.0

## Core release

V3 converts the V2 web interface into a more spatial, monumental and functional final-product mockup.

### Major changes

- Expanded desktop and ultrawide scale system.
- Minimal global navigation with progressive world explorer.
- Hub redesigned around the world and the question “¿Qué necesitás hoy?”.
- Fixed side panels removed from the Hub.
- Contextual need dock, universe drawer and message drawer.
- SØD core visually upgraded.
- New complete `/experiencia` transformation flow.
- Canonical Seed discovery and user-confirmed Code creation.
- Observatory visually reacts to local Seeds, Codes and Journey progress.
- Elementos 33 rebuilt as five monumental forces.
- Element pieces grouped by Velo, Remez, Derash, SØD and SØD².
- Fuego and Éter explicitly marked as visual placeholders.
- Library redesigned as a living archive.
- Codes redesigned as a museum and relic exhibition.
- Settings redesigned as a calibration chamber.
- Extensive responsive V3 layer for mobile, desktop and ultrawide.

### Honest limitations

- Content and inference are still MVP placeholders.
- The Hub uses Canvas plus concept art, not final 3D assets.
- Element pieces still use generated development data.
- Persistence remains local on Vercel.
- No production LLM, database, voice, blockchain or wallet is connected.
